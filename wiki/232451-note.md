# Zero Orphan Node Guarantee and Automated Maintenance
**Source:** [[2026-08-09-232451-note.md]]
**Channel / Author:** Not specified

## Summary
The [[Zero Orphan Node Guarantee]] ensures that [[AI wrappers]] do not simply dump plain text summaries into notes, but instead, behave like a human archivist by hunting for [[concepts]] and wrapping them in exact [[Obsidian wikilinks]]. This is achieved through strict [[bidirectional linking rules]] hardcoded into the [[Python script]] (`capture_bot.py`). The system also features [[Automated Nightly Maintenance]] using a [[cron job]] that processes tasks in the background and sends a clean report in the morning, leveraging a [[3-pillar architecture]] consisting of [[Wiki]], [[CRM]], and [[Journal]].

## Key Takeaways
* The [[Zero Orphan Node Guarantee]] is a key feature that prevents the creation of isolated notes by ensuring that all concepts are linked using [[Obsidian wikilinks]].
* The system uses a [[Python script]] (`capture_bot.py`) to enforce strict [[bidirectional linking rules]] and facilitate the growth of a dense and interconnected [[Knowledge Graph]].
* [[Automated Nightly Maintenance]] is performed using a [[cron job]] that runs at 10:00 PM IST to process tasks in the background.
* The [[cron job]] batches [[API calls]] and sends a clean report in the morning, providing an overview of the system's activities.
* The system's architecture is based on a [[3-pillar architecture]] consisting of [[Wiki]], [[CRM]], and [[Journal]] components.
* The engine is faster, completely free, highly customizable, and 100% locally owned, offering advantages over other solutions.

## Key Concepts
* [[Zero Orphan Node Guarantee]]: A feature that ensures all concepts are linked using [[Obsidian wikilinks]] to prevent the creation of isolated notes.
* [[Bidirectional Linking Rules]]: Strict rules hardcoded into the [[Python script]] to facilitate the growth of a dense and interconnected [[Knowledge Graph]].
* [[Obsidian Wikilinks]]: Exact links used to connect concepts and notes within the system.
* [[Automated Nightly Maintenance]]: A process that runs in the background using a [[cron job]] to process tasks and send a clean report in the morning.

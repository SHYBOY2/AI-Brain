# Uncensored AI Chat App
## Summary
This page describes a method to create an uncensored AI chat app using God Mode and OpenWebUI, allowing users to access top AI models like ChatGPT and Claude without refusals or pushback. The app can be deployed on a cloud server and accessed from anywhere in the world using any device. The setup process involves linking the app to a provider like Open Router and configuring the API version of God Mode.

## Key Takeaways
* God Mode is a tool that can intercept and modify chat inputs to force AI models to provide uncensored answers.
* OpenWebUI is a web-based chat infrastructure that can be linked to God Mode to create a fully functional AI chat app.
* The app can be deployed on a cloud server like Hostinger, which offers pre-built machines with the necessary infrastructure.
* The setup process involves creating an API key for Open Router, deploying the API version of God Mode, and linking it to OpenWebUI.
* The app can be accessed from anywhere in the world using any device, including phones, and can be added to the home screen like a normal app.
* The app provides a proper chat interface with authentication, allowing users to ask questions and receive uncensored answers from top AI models.
* The setup process requires some technical expertise, including cloning a Git repository, building a Docker image, and configuring environment variables.
* The app can be used for various purposes, including hacking and cybersecurity, and provides a convenient way to access uncensored AI models.

## Key Concepts
* **God Mode**: A tool that can intercept and modify chat inputs to force AI models to provide uncensored answers.
* **OpenWebUI**: A web-based chat infrastructure that can be linked to God Mode to create a fully functional AI chat app.
* **Open Router**: A provider that offers access to top AI models like ChatGPT and Claude.
* **API key**: A unique key used to authenticate with Open Router and access its AI models.
* **Docker**: A containerization platform used to build and deploy the API version of God Mode.
* **Cloud server**: A remote server that can be used to deploy and host the AI chat app.
* **Uncensored AI**: AI models that can provide answers without refusals or pushback, often used for hacking and cybersecurity purposes.

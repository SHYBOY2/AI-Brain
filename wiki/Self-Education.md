# Self-Education

The practice of independently acquiring knowledge and skills outside formal educational structures. The bottleneck is no longer access to information — it is the ability to convert information into **understanding**.

## The Core Problem

We have confused **consuming information** with **learning**. More YouTube, more newsletters, more podcasts — none of it builds skill or judgment unless it is actively applied and integrated.

> "Information isn't the bottleneck anymore. Understanding is." — Nextcore

## Framework for Genuine Self-Education

From [[wiki/The-Art-of-Becoming-Dangerously-Self-Educated]]:

### 1. Try First, Learn Second
- Attempt the thing before you know how to do it
- Struggle generates specific questions → specific questions lead to useful answers
- The failure itself shows you what to learn next

### 2. Learn in Public / Create Artifacts
- Leave evidence: notebooks, GitHub commits, essays, portfolios
- Creating reveals every gap in understanding (see: [[wiki/Feynman-Technique]])
- Darwin, Feynman, and every serious practitioner does this

### 3. Go to Primary Sources
- Most online content is n-th order derivative — stripped of evidence, nuance, and context
- Primary sources: original studies, original texts, the people who built the thing
- Slower, but the only path to independent judgment
- See: [[wiki/Primary-Sources]]

### 4. Embrace Boredom and Confusion
- Understanding often arrives silently — then suddenly clicks
- Escaping difficulty with more content is the main failure mode
- See: [[wiki/Deep-Work]]

## The 85/15 Rule

From [[wiki/Why-You-Should-Stop-Watching-YouTube]]:
- 15% of learning = information intake
- 85% = implementation and doing

Watching content without implementation is not learning. It is entertainment with a productivity costume.

## Self-Education vs. School

| School | Self-Education |
|--------|---------------|
| Learn first, practice later | Try first, get stuck, learn specifically |
| Structured curriculum | Struggle-driven curriculum |
| External validation | Internal feedback loops |
| Passive reception | Active production |

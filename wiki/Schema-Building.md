# Schema Building

Schema building is the cognitive process of organizing knowledge into connected, hierarchical networks. It is the single most important process for creating **durable, high-quality memory** that can be used for complex tasks.

## What It Is

A **schema** is an organized body of information where concepts are linked by their relationships — how ideas compare, contradict, cause, or depend on each other. Memory formed through schema building is:

- Deep and robust
- Transferable to new situations
- Usable for problem-solving, writing, and decision-making

## Why It Matters

Learning that does not support schema building produces **isolated facts**: knowledge that can be recognized in the exact form it was learned, but cannot be applied flexibly. This is the core failure mode of flashcards, highlighting, and rereading.

> The ability to solve complex problems, write essays, and make decisions based on what you've learned depends almost entirely on schemas — not on the number of facts you've memorized.

## How Schemas Form

1. **Comparative thinking** — Evaluating how one idea differs from or relates to another
2. **Hierarchical organization** — Identifying what is more or less important; what is a cause vs. an effect
3. **Contradiction resolution** — Noticing where new information conflicts with existing understanding and integrating it
4. **Externalization** — Writing or drawing forces the brain to make tacit structure explicit (see: [[wiki/Mind-Mapping]])

## Techniques That Support Schema Building

| Technique | Schema Support | Notes |
|-----------|---------------|-------|
| Mind Mapping (correct) | ✅ High | Forces visual organization of connections |
| Feynman Technique | ✅ High | Forces narrative logic and simplification |
| Interleaving (Sung version) | ✅ High | Tests knowledge from multiple angles/levels |
| Cornell Notes | ⚠️ Partial | Only if questions are deep and comparative |
| Blurting / Brain Dump | ❌ Low | Tests isolated recall, not connections |
| Flashcards | ❌ Low | Isolated cued recall |
| Rereading | ❌ None | Passive familiarity only |
| Highlighting | ❌ None | No cognitive engagement |

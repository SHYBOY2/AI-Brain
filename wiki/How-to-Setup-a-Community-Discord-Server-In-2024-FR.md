# How to Setup a Community Discord Server In 2024
**Source:** [[2026-08-10-How-to-Setup-a-Community-Discord-Server-In-2024-FR.md]]
**Channel / Author:** DesignerJenil

## Summary
To set up a [[Community Discord Server]], you need to create different [[Categories]] such as [[Get Started]], [[Community Category]], [[Voice Channel]], and [[Private Management Category]]. You also need to create various [[Channels]] like [[Welcome Channel]], [[About Me Channel]], and [[Info Channel]]. Additionally, setting up [[Roles]] like [[Founder Role]], [[Admin Role]], [[Moderator Role]], and [[Member Role]] is essential for managing your server. You can use [[Sapphire Bot]] to automatically assign [[Member Roles]] to new users.

## Key Takeaways
* Create four different [[Categories]]: [[Get Started]], [[Community Category]], [[Voice Channel]], and [[Private Management Category]]
* Set up various [[Channels]] like [[Welcome Channel]], [[About Me Channel]], and [[Info Channel]]
* Create [[Voice Channels]] with limitations on users joining them
* Disable all [[System Messages]] except when someone [[Boosts the Server]]
* Create [[Roles]] like [[Founder Role]], [[Admin Role]], [[Moderator Role]], and [[Member Role]]
* Use [[Sapphire Bot]] to automatically assign [[Member Roles]] to new users
* Enable the [[Community Feature]] on your server by going to [[Server Settings]] and clicking on the [[Enable Community Option]]
* Set up [[Permissions]] for each [[Category]] and [[Channel]] to control what users can do

## Key Concepts
* [[Community Discord Server]]: a server where people can come together to discuss common interests
* [[Categories]]: a way to organize [[Channels]] on a [[Discord Server]]
* [[Channels]]: a place where users can communicate with each other
* [[Roles]]: a way to assign permissions to users on a [[Discord Server]]
* [[Sapphire Bot]]: a bot that can automatically assign [[Member Roles]] to new users
* [[System Messages]]: messages that are sent by the [[Discord Server]] itself
* [[Boosting the Server]]: a way to support a [[Discord Server]] by giving it a boost
* [[Permissions]]: a way to control what users can do on a [[Discord Server]]

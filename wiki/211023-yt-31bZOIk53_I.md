# VALL-E Voice: A Free Voice Calling Tool
## Summary
Microsoft developed VALL-E Voice, a voice calling tool that can generate realistic voices, but it was taken off the market due to concerns about deep fakes. The project was open-sourced, and community members saved copies of the repository before it was removed. This tool can be used to clone one's voice and create AI audio without subscription fees. VALL-E Voice can also generate audio in multiple languages and has various use cases, including custom audio for customers, translating blog posts into audio, and creating audiobooks.

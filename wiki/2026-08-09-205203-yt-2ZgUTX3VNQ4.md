## Summary
Elicitation is a powerful technique used to extract information from individuals without directly asking questions, thereby avoiding the brain's natural security alarms. This method, originally developed by the CIA, involves using statements instead of questions to trigger a response, making the person feel like they are volunteering information.

## Key Takeaways
* Elicitation is a technique that uses statements instead of questions to extract information
* It can be used to trigger a need to correct the record, making the person feel like they are volunteering information
* Three key layers of elicitation are: triggering a need to correct the record, making a statement and waiting for a response, and using disbelief to extract more information
* Elicitation can be used in various contexts, including business intelligence and social interactions
* Techniques such as bracketing and disbelief can be used to extract more information from individuals

## Key Concepts
Elicitation is a technique that involves using statements to extract information from individuals, making them feel like they are volunteering information. Key concepts include:
* Triggering a need to correct the record
* Making statements instead of asking questions
* Using disbelief to extract more information
* Bracketing: giving a series of options to extract more information
* Disbelief: expressing doubt or surprise to extract more information

# Create Any Discord Bot With AI | CraftCord AI Full Tutorial
**Source:** [[2026-08-10-Create-Any-Discord-Bot-With-AI-CraftCord-AI-Full-T.md]]
**Channel / Author:** CraftCord

## Summary
The [[CraftCord AI]] platform allows users to create powerful [[Discord bots]] by simply describing what they want, and the [[AI]] will build it for them. To get started, users can log in and activate a [[24-hour free trial]] to explore the available [[features]] and choose a plan that fits their needs. The process involves creating a [[bot token]] from the [[Discord developer portal]] and using the [[AI command builder]] to create custom [[commands]].

## Key Takeaways
* [[CraftCord AI]] is a paid service that offers a [[24-hour free trial]] to test its features.
* To create a [[Discord bot]] with [[CraftCord AI]], users need to log in and activate their free trial.
* The [[Discord developer portal]] is used to create a [[bot token]] and invite the bot to a [[Discord server]].
* The [[AI command builder]] allows users to create custom [[commands]] by describing what they want.
* [[Intents]] such as [[presence intent]], [[server members intent]], and [[message content intent]] need to be enabled for the bot to function properly.
* Users can upgrade to a paid plan for faster response times and more features.
* The [[CraftCord AI]] website can be found in the description of the video for further information.
* [[Music]] bots can be created using [[CraftCord AI]] by following the same process.

## Key Concepts
* [[CraftCord AI]]: A platform that allows users to create powerful [[Discord bots]] using [[AI]].
* [[Discord bots]]: Automated programs that can perform various tasks on [[Discord servers]].
* [[AI command builder]]: A tool that allows users to create custom [[commands]] by describing what they want.
* [[Bot token]]: A unique token required to authenticate and authorize a [[Discord bot]].
* [[Intents]]: Specific permissions that need to be enabled for a [[Discord bot]] to function properly.
* [[Discord developer portal]]: A website that provides tools and resources for developers to create and manage [[Discord bots]].
